## V1.1.5 正式版更新

相对公开的V1.1.0预发布版，汇总V1.1.1～V1.1.5的画质、详情预加载与HDR兼容修复。保留现有四套主题和遥控器界面。

- **统一清晰度目录与真实画质状态**：默认设置与播放器共用档位，保留8K、HDR、高帧率及服务端合法新档位；当前视频只展示平台实际提供的信息。目标档位与实际输入、首帧确认、显示输出分别表达。
- **修复默认4K落到1080P60**：已保存的具体清晰度不再被固件漏报的1080P自动显示上限覆盖。明确设置的最高1080P/最高4K上限仍有效；编码作为同档偏好，保留解码能力、HDR、账号与片源限制。
- **详情页播放预加载**：新增关闭、智能、增强模式，进入当前详情后进行有预算的准备，正式播放时复用。计费网络、低内存、后台、账号或儿童授权变化时按策略降级或取消；未点击播放不写观看历史、不出声。
- **修复20分钟位置续播接管**：按有效续播锚点准备和构建媒体源，修复把绝对时间误作缓冲时长、先从0秒构建再跳转导致准备失效的问题。
- **HDR兼容回退更准确**：杜比显示条件不满足时，优先使用片源提供、解码能力已确认且尺寸/帧率合适的HDR10/HLG轨道；仍遵守固定上限及优先SDR设置，不把杜比源改名冒充HDR。
- **区分盒子解码和电视显示能力**：显示HDR列表为空时，HDR10/HLG可在播放设置中确认“本次兼容试播”后手选。杜比视界仍要求显示端支持，不加入强制杜比或未经验证的隧道策略。
- **兼容分支同步**：补齐Android5～7的显示接口、儿童模式安全存储等兼容处理，保留旧引擎；兼容版仅进行描述信息准备，不启用标准版的媒体队列或准备态播放器预热。

标准版已在Android11盒子验证保存默认4K后的3840×2160输入、真实4K HDR10与HDMI HDR10状态、20分钟续播准备接管。最终HDR回退相关回归标准版365项、兼容分支378项零失败；这不是全部功能、全部设备的覆盖证明。预加载效果取决于详情停留时间、网络、编码和设备，不承诺所有页面或资源提速50%。

**电视能力示例**：Sony KD-55X8000G支持HDR10/HLG，其HDMI不支持杜比视界；盒子有杜比解码器也不能补出电视端能力。[索尼官方兼容表](https://support.sony.jp/electronics/support/articles/00161421)。真实8K约30fps和4K HDR约60fps有有限设备验证，不等于8K60或跨设备杜比输出认证。

### 历史更新：V1.0.90 相比 V1.0.73

本次包含 **V1.0.74～V1.0.90** 的新增功能与优化，标准版和兼容测试版同步到 V1.0.90。

#### 新增功能

- **儿童模式**：在“设置 → 通用 → 儿童模式”中开启。登录后由家长设置6位PIN、选择一个允许观看的收藏夹，进入受限浏览与播放界面；退出及家长设置需要PIN验证。不是自动内容分级或平台级家长控制，收藏夹内容仍需家长自行选择。
- **个人信息中心**：已登录时点击左侧头像，可查看关注/粉丝、近期关注博主及追番/追剧订阅信息，进入订阅列表、刷新数据或确认退出；未登录时仍进入扫码登录。
- **播放中直达博主空间**：普通视频控制条新增圆形博主头像，可用遥控器或触摸进入作者的视频列表，跳转前暂停当前播放。
- **观看历史同步**：登录账号播放后，按实际播放进度向平台提交观看记录；暂停、离开及结束时补交进度，返回“我的 → 历史”时刷新列表。游客不提交，网络失败不阻断播放，也不承诺强制结束进程前的记录一定已上传。
- **HDR本次兼容试播**：针对设备显示能力报告不完整的情况，提供用户主动开启的本次试播入口，默认关闭、进入新视频后重置；不更改系统HDR设置，失败仍按恢复策略处理。

#### 播放稳定性与高规格视频优化

- **更有依据地选择播放源**：结合编码、分辨率、帧率、设备解码与显示能力选择画质，改进手动高规格选源及当前选择状态显示；能读取到的实际输入信息才用于判断，不把菜单中的“4K/8K/HDR”当作实际输出证明。
- **改进颜色识别与兼容回退**：需要恢复时，按需识别媒体初始化信息，改善HDR/SDR判断及候选选择；信息不足时保留“未知”，避免把未知来源误判为SDR。
- **反复缓冲有限恢复**：检测短时间内多次缓冲，并结合实际吞吐和可用候选，在条件满足时尝试一次较低码率恢复；保留进度与暂停意图，不无限重试、不自动改写全局默认画质。
- **改善播放器重建后的恢复**：优化重播、页面/播放器重建与焦点恢复，减少返回后焦点错位和播放状态衔接问题。

#### 遥控器与电视界面优化

- **播放设置更紧凑**：使用半宽侧边面板，减少重复说明；设置名称和当前值按实际宽度适配，避免省略和溢出。V1.0.90最终将文字高度上限设为功能项行高的60%，保持原行高与间距。
- **控制条按空闲时间隐藏**：默认3秒；遥控器按住或连续操作时保持显示，最后松键后重新计时。设置等交互面板打开时保持可见，直播同步优化。
- **控制条与头像布局统一**：电视端采用更紧凑的控制条；博主头像与同排按钮等高、所在区域等宽并居中，减少对视频画面的遮挡。
- **电视列表与焦点修复**：修复直播首次加载未从首行显示的问题；改善进入详情、从播放返回详情时的焦点恢复，以及电视详情页相关视频卡片的排列和滚动。
- **桌面横幅修复**：调整电视桌面图标/横幅的缩放与布局，改善部分启动器上的裁切、缩小及留白问题。

#### 兼容版同步与验证边界

- 独立兼容版同步上述业务改动，保留Android5～7的依赖、显示接口与加密登录保存适配；同签名旧兼容版可覆盖升级，与标准版仍独立安装。
- 标准版的部分播放、账号读取、历史同步及设置布局已有设备实测；兼容分支构建与测试报告汇总1135项零失败，包含缓存及UP-TO-DATE任务。**本次兼容包未做Android5～7真机验收**。
- HDR、4K/8K及高帧率效果取决于片源、账号权限、设备解码和显示链路；部分设备上的有限时长验证不代表所有设备支持，8K60及跨厂商长时间场景仍待验证。
- 部分设备的系统MENU键仍待专项兼容核查，可使用屏幕控制条中的设置入口。儿童模式的账号过期、收藏夹权限变化、长时间播放及系统恢复等异常组合仍需继续验收。

## 遥控器操作

| 操作 | 说明 |
| --- | --- |
| 方向键 | 在导航、视频卡片和设置项之间移动焦点 |
| 确认键 / OK | 激活当前按钮或卡片；输入框获得焦点后，确认可唤起系统输入法 |
| 返回键 / BACK | 关闭当前面板、返回上一级；播放页会结合当前控制栏/弹窗状态处理返回 |
| 菜单键 / MENU | 在播放页打开播放设置；没有菜单键时可使用屏幕控制栏的设置入口 |
| 播放页左右键 | 在进度操作状态下快退/快进，长按可连续调整；设置面板内按面板提示操作 |

直播与点播的可用操作不同，直播不提供点播式进度拖动。不同遥控器的按键上报和系统输入法行为可能不同，请以界面提示为准。
